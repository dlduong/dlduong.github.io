# Interactive MCMC crash course

Open index.html in a modern browser. No build, server, account, or external scripts are required. Native MathML renders the equations. The live lab implements scalar random-walk Metropolis and fixed-length HMC, with a deterministic pseudorandom seed reset on Reset. The course contains the full six-part lesson, summary, concept map, and exercise solutions.

Source: the MCMC crash-course conversation with Duc-Lam Duong, 5–6 November 2026; the complete lesson text is embedded in index.html. Future coding agents should treat this lesson as the content source, preserve the mathematical qualifications, and check samplers against N(1.6,0.2). Do not label the fixed-length HMC demonstration as NUTS.

Run the companion Python examples with NumPy, SciPy and Matplotlib installed. They write plots and diagnostics into results/. The browser demonstration is educational and includes its initial transient; it does not certify convergence.
